# 4주차 LLM 추론과 프롬프트 실험

이번 주 실습은 **작은 사전학습 LLM 질문 응답 CLI**입니다. 대응 ID는 L16~L20, 계획시간은 30시간입니다.

[참고 자료](RESOURCES.md) · [데이터와 모델 링크](DATA.md) · [체크리스트](CHECKLIST.md)

## 과제

작은 사전학습 causal LM을 직접 불러와 추론합니다. 기본 모델 후보는 Qwen3-0.6B이며 모델 카드의 지원 조건을 확인합니다. CPU에서 실행시간을 먼저 측정하고 긴 출력이나 사고 모드는 필요한 범위로 제한합니다.

tokenizer로 한국어·영어·공백이 다른 입력의 token 수를 비교합니다. chat template, role, context budget, 생성 토큰 수와 입력·출력 분리를 확인합니다.

프롬프트와 생성 설정을 한 번에 하나씩 바꾸어 결과를 비교합니다. 동일한 테스트 질문 10개를 정해 출력·지연·실패를 기록하고 JSON 형식 출력은 실제로 파싱해 확인합니다.

모델을 매 질문마다 다시 로드하지 않는 CLI를 구성합니다. 빈 입력, 너무 긴 입력과 형식 실패의 동작을 정하고 모델·설정·토큰·시간을 결과에 기록합니다. 미세조정과 전체 모델 학습은 필수 범위에 포함하지 않습니다.
