# 5주차 문서 청킹 임베딩과 검색 평가

이번 주 실습은 **Python 문서 검색기와 개발 평가셋**입니다. 대응 ID는 L21~L25, 계획시간은 30시간입니다.

[참고 자료](RESOURCES.md) · [데이터와 모델 링크](DATA.md) · [체크리스트](CHECKLIST.md)

## 과제

Python 공식 한국어 자습서의 지정한 8개 페이지를 직접 확보해 로컬 snapshot으로 고정합니다. 본문, 제목, URL, 문서 ID, 수집 시점과 hash를 기록하고 메뉴·중복 텍스트를 구분합니다.

문서를 chunk로 나누고 원본 위치, chunk ID, 길이와 overlap 설정을 기록합니다. embedding 모델의 실제 입력 토큰 제한을 확인하고 조용히 잘리는 chunk 비율을 점검합니다. 문자 수를 토큰 수로 간주하지 않습니다.

다국어 sentence embedding으로 문서와 질문을 벡터화하고 NumPy cosine 계산으로 top-3를 직접 구합니다. 동일한 모델·revision·정규화 규칙을 문서와 질문에 적용합니다. 임베딩 모델의 차원과 토큰 제한은 모델 카드에서 확인합니다.

TF-IDF 검색 baseline과 dense 검색을 비교합니다. 학습자는 개발 질문 20개를 만들며 그중 5개는 문서에 근거가 없는 질문으로 정합니다. 교육자는 별도 최종 질문 10개 중 3개를 근거 없는 질문으로 준비하고 마지막 평가 전까지 보관합니다.

답할 수 있는 개발 질문에는 정답 문서 ID와 근거 위치를 표시합니다. 검색 top-3의 문서 ID를 기준으로 Recall@3를 계산하고 실패 사례를 분석합니다. 생성 모델을 연결하기 전에 검색 결과와 근거를 직접 확인합니다.

질문과 문서의 벡터를 설명하고 top-3 근거를 원문에서 찾으며 검색 실패를 생성 실패와 구분한다.
