# AI 개발과 LLM RAG 실습 6주 과정

이 저장소는 Python과 데이터 처리의 기초부터 작은 사전학습 LLM 추론과 문서 기반 RAG까지 직접 구성하는 실습 자료입니다. 구현 방법은 참고 문서에서 찾아 선택하고, 매주 실행·설명·검증 근거를 제출합니다.

기준은 **6주 30학습일, 주 5일, 하루 6시간, 총 180시간**입니다. 하루 4시간만 확보할 수 있다면 같은 180시간은 약 9주가 필요합니다. 일정은 교육자와 정하고 필수 목표를 기능 추가보다 먼저 확인하세요.

## 진행 방식

저장소를 클론하고 자신의 작업 브랜치에서 실습합니다. 원본 저장소에 쓰기 권한이 없으면 교육자가 정한 fork 또는 개인 저장소를 사용하세요. 매주 PR 또는 커밋 링크와 보고서를 제출합니다. 명령과 코드 구조는 직접 정하고 실제 실행 방법을 결과 README에 적습니다.

AI와 공식 예제를 참고할 수 있습니다. 주요 함수의 입력·출력, 변경 이유와 검증 방법은 직접 설명합니다. 직접 선택한 자료구조, 데이터 분할, 모델·생성 설정과 검색 규칙을 기록하세요.

코드·문서·작은 결과표를 Git에 남깁니다. 원본 데이터, 모델 가중치, 임베딩·인덱스 바이너리, 가상환경과 인증 정보는 로컬에서 관리하고 필요한 제외 설정을 직접 작성합니다.

최종 결과는 작은 RAG CLI입니다. 전체 LLM 학습, 미세조정, UI, 서버와 배포는 선택 과제입니다. 자료 확인일은 2026-10-06입니다.
