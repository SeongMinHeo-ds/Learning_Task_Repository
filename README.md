## 작업 방식

저장소를 클론해 내용을 확인하고 개인 작업 브랜치에서 실습하세요. 같은 저장소에 쓰기 권한이 없다면 교육자가 정한 개인 저장소 또는 fork에서 진행하세요. 브랜치와 원격 저장소의 사용법은 참고 문서에서 찾아보세요.

한 주의 작업은 한 개의 PR로 제출합니다. PR 권한이 없다면 해당 작업의 커밋 링크와 주간 보고서를 제출합니다. 제출 전 스스로 코드를 실행하고 주차별 체크리스트를 확인하세요.

## 직접 결정할 부분

파일 구조, 함수 이름, 실행 인자 이름, 전처리의 세부 선택과 실험 설정은 직접 정합니다. 선택한 이유와 검증 방법을 기록하세요. 예제나 AI를 참고했다면 출처와 수정한 내용을 설명하세요.

기능을 실행할 수 있고, 주요 코드의 입출력과 변경 이유를 설명하며, 결과를 확인한 근거를 보여주어야 완료입니다.
