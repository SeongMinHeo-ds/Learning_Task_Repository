# 2주차 목표 체크리스트

조건을 충족하고 증빙을 남긴 항목만 체크합니다. 최종 holdout은 이번 주 모델 선택에 사용하지 않습니다.

- [ ] **L06 Titanic 데이터 이해** — 데이터 확보와 열 설명을 마쳤다. 입력, 정답, ID, 결측과 범주를 구분하고 train 중심 탐색 결과를 남겼다.
- [ ] **L07 데이터 분할과 baseline** — train, validation, holdout의 규칙과 seed를 기록하고 중복 여부를 확인했다. DummyClassifier 결과와 지표 선택 이유를 설명한다.
- [ ] **L08 전처리와 Pipeline** — 결측 처리와 범주 인코딩을 필요한 열에 적용한다. 전처리 fit에 사용한 데이터를 밝히고 같은 변환으로 예측한다.
- [ ] **L09 모델 비교와 평가** — LogisticRegression과 작은 트리를 baseline과 동일 분할에서 비교했다. confusion matrix와 오류 사례를 설명한다.
- [ ] **L10 저장과 예측 파일** — Pipeline을 저장·재로드하고 같은 입력의 예측 일관성을 확인했다. 예측 CSV의 스키마와 ID 대응을 확인했다.
