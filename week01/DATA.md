# 1주차 데이터와 모델 링크

다운로드 대상은 아래 링크에서 직접 확보하세요. 이 자료에는 원문·데이터·모델 가중치 파일이 들어 있지 않습니다.

- [UCI Wine 데이터와 설명](https://archive.ics.uci.edu/dataset/109/wine)

## 확보한 뒤 확인할 사항

- 원본 파일과 열 설명을 직접 확인합니다. 파일 형식을 바꾸었다면 변경 내용을 기록합니다.
- 오류 입력은 원본의 작은 복사본에서 직접 만들고 원본을 보관합니다.

출처·확보 날짜·원본 파일 또는 모델명·버전·로컬 경로·사용 범위를 기록합니다. 라이브러리는 [이름 목록](../LIBRARIES.md)을 확인합니다.
