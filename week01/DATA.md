# 1주차 데이터 링크

## Wine

- [UCI Wine 데이터와 설명](https://archive.ics.uci.edu/dataset/109/wine)

출처 페이지의 다운로드 기능을 사용해 원본과 설명 파일을 확보합니다. 원본 파일명, 구분자, 헤더 유무, 첫 번째 열의 의미를 직접 확인하세요. 이 패키지에는 데이터 파일이 들어 있지 않습니다.

Wine은 13개 측정 특성과 분류 대상을 가진 데이터입니다. 이번 주에는 모델 학습보다 데이터 읽기와 결과 확인에 사용합니다. 원본 데이터의 `wine.names` 설명도 참고하세요.

## 확보한 뒤 기록할 내용

- 출처와 확보 날짜
- 사용한 파일명과 로컬 위치
- 입력 열의 이름과 순서, 정답 열의 의미
- 읽었을 때의 행·열 수와 자료형
- 헤더나 형식을 변경했다면 변경한 내용

원본을 보관하고 잘못된 데이터 입력은 작은 복사본으로 직접 만드세요. 인위적으로 바꾼 값은 연습용이며 원본의 특성으로 해석하지 않습니다.
