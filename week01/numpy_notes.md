# L04 NumPy 연산 손계산 대조 및 메모리 검증 노트 (numpy_notes.md)

## 1. 기본 규격 및 Shape
- **배열 A**: shape `(2, 3)`, dtype `int32`
- **원소 개수 보존**: `2 * 3 = 6`개 원소가 `reshape(3, 2)` 후에도 총 6개 유지
- **A > 3 불리언 마스크**: `[4, 5, 6]` (순서: 1행부터 스캔되어 4, 5, 6 추출)

## 2. 연산별 입력·Shape·손계산 대조표
| 연산 | 수식 / 표현식 | 입력 Shape | 출력 Shape | 결과 | 손계산 및 Python 반복문 대조 |
|---|---|---|---|---|---|
| 축 0 합 | `A.sum(axis=0)` | `(2, 3)` | `(3,)` | `[5, 7, 9]` | `[1+4, 2+5, 3+6] = [5, 7, 9]` (일치) |
| 축 1 합 | `A.sum(axis=1)` | `(2, 3)` | `(2,)` | `[6, 15]` | `[1+2+3, 4+5+6] = [6, 15]` (일치) |
| 전체 합 | `A.sum()` | `(2, 3)` | scalar | `21` | 반복문 합 `21`과 일치 |
| 축 0 평균 | `A.mean(axis=0)` | `(2, 3)` | `(3,)` | `[2.5, 3.5, 4.5]` | `[5/2, 7/2, 9/2] = [2.5, 3.5, 4.5]` |
| 축 1 평균 | `A.mean(axis=1)` | `(2, 3)` | `(2,)` | `[2.0, 5.0]` | `[6/3, 15/3] = [2.0, 5.0]` |
| 브로드캐스팅 | `A + b` | `(2, 3) + (3,)` | `(2, 3)` | `[[11, 22, 33], [14, 25, 36]]` | `b`가 각 행에 확장 더해짐 |
| 원소별 곱 | `A * A` | `(2, 3) * (2, 3)` | `(2, 3)` | `[[1, 4, 9], [16, 25, 36]]` | 위치별 단순 제곱 |
| 행렬곱 | `A @ A.T` | `(2, 3) @ (3, 2)` | `(2, 2)` | `[[14, 32], [32, 77]]` | 행벡터와 열벡터의 내적 계산 |

## 3. View(Slice) vs Copy 동작 차이
1. **Slice (View)**
   - `slice_view = A[0, :]` 후 `slice_view[0] = 99` 변경 시
   - 원본 배열 `orig_for_slice[0, 0]`도 `99`로 **함께 변경됨** (`[[99, 2, 3], [4, 5, 6]]`)
   - 이유: 슬라이싱은 새로운 메모리를 할당하지 않고 원본의 메모리 주소를 참조하는 view를 반환하기 때문
2. **Copy (독립 복사)**
   - `copy_arr = A.copy()` 후 `copy_arr[0, 0] = 99` 변경 시
   - 원본 배열은 `[[1, 2, 3], [4, 5, 6]]`로 **변경되지 않고 보존됨**
   - 이유: `copy()`는 독립적인 연속 메모리 블록을 새로 할당하여 데이터를 복제하기 때문
