# 1주차 참고 자료

먼저 과제를 읽고 필요한 부분을 찾아보세요. 링크 전체를 정독할 필요는 없습니다. 아래 자료는 구현 예시를 포함하지만 과제의 입력과 출력에 맞추는 일은 직접 수행합니다.

## 먼저 볼 자료

| 자료 | 찾아볼 내용 | 연결 목표 |
|---|---|---|
| [Software Carpentry Unix Shell](https://swcarpentry.github.io/shell-novice/) | 경로, 파일 확인, 출력 저장, 사용하는 셸 | L01 |
| [Shell Scripts](https://swcarpentry.github.io/shell-novice/06-script.html) | 스크립트의 역할, 실행, 인자 | L01·L03 |
| [Python 가상환경](https://docs.python.org/3/tutorial/venv.html) | 프로젝트 환경과 패키지 관리 | L01 |
| [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) | 데이터 확인, 선택, 요약, 결측과 입출력 | L02 |
